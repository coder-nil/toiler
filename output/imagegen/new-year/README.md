# Toiler 元旦插画预览

本目录用于预览素材，不代表已接入应用或已部署 Cloudflare。

## 图片制作

- 通过 imagegen 技能的 CLI/API 编辑模式，使用 `gpt-image-2`，以现有 Toiler 图标作为品牌参考。
- 完整提示词见 `toiler-new-year-prompt.txt`；输出画稿为 `toiler-new-year-white.png`。
- 画面采用香槟金 T、冰蓝与金色彩带、小烟花；保留 `>_` 标记，不画死年份。
- CLI 对 `gpt-image-2` 不开放透明背景参数，本次以白底提示生成；服务实际返回带透明通道的 RGBA PNG，尺寸为 2172 × 724。透明通道已原样保留，没有额外抠图。
- `toiler-new-year.png` 是保留透明通道的原尺寸素材，`toiler-new-year.webp` 是 1080 × 360 的交付候选。
- `toiler-new-year-light-dark-preview.png` 用于检查深浅背景效果。
- `toiler-new-year-page-preview.png` 是基于用户截图合成的页面预览，不是运行中应用的截图；其中插画按 480 × 160 放置。

## Cloudflare 接入方案（待实现）

图片可以远程托管，不需要把全部节日资源打包到应用。推荐 R2 存放版本化图片，Worker 提供只读的当前插画接口；图片通过 R2 自定义域名或 Worker 的 R2 绑定对外服务，私有桶本身不会自动产生公开地址。应用内保留默认品牌图用于离线回退。

1. 美术资源制作、检查后上传 R2，图片地址包含版本号或内容哈希，设置长期 immutable 缓存。
2. Worker 根据服务器当前时间，使用明确的 `Asia/Shanghai` 日历规则挑选插画。元旦窗口建议是 12 月 31 日零点至 1 月 4 日零点，结束时刻不包含在内。
3. 元旦等节日规则优先于季节规则；元旦是公历节日，农历节日按农历或年度排期表，四季仍按四立的实际交节瞬间。
4. 接口返回插画标识、公开图片地址、无障碍说明、有效起止时间、下一次变化时间和服务器时间。没有匹配节日时返回季节图或默认图。
5. JSON 接口短缓存，缓存有效期不超过下一次切换边界；版本化图片长期缓存。公开只读接口允许匿名跨域，不向客户端分发 Cloudflare 或生成服务密钥。
6. 应用先展示有效的本地缓存，后台获取规则；首次离线时展示默认图。启动、恢复前台、休眠唤醒及到达下一变化时间时重新判断。已过期的节日缓存不能无限沿用。

接口示意（尚未部署）：

```http
GET /v1/doodle/current
```

```json
{
  "id": "new-year-v1",
  "imageUrl": "https://assets.example.com/doodles/new-year-v1.webp",
  "alt": "Toiler 元旦主题插画",
  "timeZone": "Asia/Shanghai",
  "serverTime": "2026-12-31T01:00:00Z",
  "validFrom": "2026-12-30T16:00:00Z",
  "validUntil": "2027-01-03T16:00:00Z",
  "nextChangeAt": "2027-01-03T16:00:00Z"
}
```

Worker 在每次请求时选图即可，不必为切换图片设置定时任务。已经打开的页面仍需要自己的边界刷新逻辑。后续只更新远程图片与排期即可，无需为每个节日重新发布桌面应用。
