# 四季应用图标

四张 512×512 RGBA PNG 来自 `output/imagegen/seasons/` 的四季概念图，
使用原版应用图标的透明轮廓统一外边缘，避免 Dock 出现黑色方框。
Rust 通过 `include_bytes!` 嵌入，不依赖外部图片目录或联网。

按电脑本地时间采用北半球月份划分：3–5 月春、6–8 月夏、9–11 月秋、12–2 月冬。
收到 Tauri `Ready` 事件后设置一次，运行期间每分钟检查，只有季节变化才重新解码和设置图标；
切换失败会保留旧图标并在下次检查重试。退出时取消检查任务。

不能提前到 `setup` 设置：Tauri 在 `setup` 之后处理 `Ready` 时可能覆盖 macOS 的
Dock 默认图标。它发生在用户的 `Ready` 回调之前，季节图标必须在该回调里最后设置。

macOS 更新运行中应用的 Dock 图标，Windows/Linux 更新窗口图标（任务栏是否跟随
由桌面环境决定）。不修改已签名应用包：Finder、启动器和固定快捷方式的静态
图标仍然使用原版 Toiler 图标。网页 favicon、手机主屏图标不参与本轮轮换。
