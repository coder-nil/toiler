Toiler

这是内置的占位页：二进制里没有嵌入真实前端产物。

后端已经完全可用，接口同源挂在 /api 下：

  • GET /api/sessions — 会话列表
  • GET /api/models — 模型目录
  • GET /api/mobile/state — 手机访问状态

要嵌入真实前端，构建时指定产物目录后重新编译：

TOILER_FRONTEND_DIR=/path/to/frontend cargo build -p toiler-desktop --release

产物需包含 index.html（pi 的 Next 静态导出形状： index.html / index.txt / _next/ / icons/）。
